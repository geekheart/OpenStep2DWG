## 真实模型

| 模型 | 测试方式 | 尺寸 X × Y × Z（mm） | 轮廓数 | 备注 |
|---|---|---|---:|---|
| DEMO-BOARD | 浏览器 STEP → DWG | 56 × 28 × 6.6 | 124 | 40 个通孔；可复现示例 |
| WT9932S31-TINY | 浏览器 STEP → DWG | 53.51897 × 27.97992 × 13.34716 | 20,434 | Chrome 全流程约 4.3 分钟 |
| WT9932P4-TINY | 同一 WASM 内核，经 Node 调用 | 68.97474 × 27.97466 × 15.50005 | 17,410 | 简化移除 843 个板面薄层 |

S31 与 P4 分别有 284 / 461 条当前内核不能直接转成原生曲线的轮廓，按 0.01 mm 公差离散为 LWPOLYLINE；该数量在项目中保存并向用户显示。其余曲线保留 LINE / ARC / SPLINE。

这些真实模型只用于本地回归，不随仓库或 Pages 发布。

## 导入性能复测

S31（26.42 MiB），Chrome、本地静态服务器、完整几何、正面 / 背面 / 前侧。阶段时间由 Worker 的实际阶段边界记录；不代表公网下载速度。

| 阶段 | 耗时 |
|---|---:|
| 下载压缩内核并初始化 | 1.3 秒 |
| STEP 解析与实体构建 | 28.7 秒 |
| 精确外形尺寸 | 47.0 秒 |
| 三视图精确投影 | 175.2 秒 |
| 首次完成并显示 | 252.4 秒 |
| 刷新后，同文件、同参数从本地缓存恢复 | 0.2 秒 |

缓存复测时阻断全部内核资源请求，仍成功显示 20,434 条轮廓。新结果与优化前 S31 的三视图实体参数及外形尺寸逐项严格相等；DWG 导出后再次通过 ODA 独立回读。视觉检查确认缓存恢复后的图纸、尺寸标注与排版正常。

缓存与复用不改变首次精确投影的计算复杂度；首次处理新模型仍需等待本机 CAD 计算。

## 独立 CAD 回读

开发阶段使用官方 ODA File Converter 27.1 将 WASM 生成的 DWG 回读为 DXF，再由独立 ezdxf 解析：

- 示例、S31、P4 的实体类型和数量一致。
- 比较直线端点、圆弧参数、样条控制点 / 节点 / 权重、尺寸定义点及比例系数，保留 7 位小数，无不匹配实体。
- 三份图纸均为 AC1015、毫米单位；审计错误为 0。
- S31 尺寸：53.51897、27.97992、13.34716 mm。
- P4 尺寸：68.97474、27.97466、15.50005 mm。
- 对回读图纸进行了视觉检查，图框、三视图、尺寸与标题栏正常。

独立校验器：

```sh
python -m pip install ezdxf==1.4.3
python scripts/verify-dxf.py source.dxf oda-roundtrip.dxf verification.json
```

ODA 仅用于开发验证，不在应用中运行，不包含在分发文件中。内置浏览器检查使用 acadrust 自身回读和实体数量核对，不能视为对所有 CAD 版本的完整兼容性认证。
