# OpenStep2DWG V1.0.1

## 简体中文

- 统一应用代码为 MIT 协议，版权署名为 2026 geekheart；保留 CAD 内核与其他依赖的独立许可证。
- 保留中文默认 README，增加完整英文 README，顶部可互相切换。
- 新增简体中文 / English 界面切换及 `?lang=en` 英文直达链接；菜单、参数、导出弹窗、校验错误、Worker 进度、状态提示和可访问性文本均提供英文。
- 语言切换保留当前模型、排版、撤销记录及用户输入；不更改 CAD 几何算法、毫米单位、文件格式和标准字段。
- 顶部新增 GitHub SVG 图标按钮，一键打开源码仓库。
- 发布工作流使用本文件中的双语说明，检查通过后发布 Pages 和静态站点 ZIP、SHA-256 校验和。

## English

- Standardized the application license to MIT, copyright 2026 geekheart. CAD engines and other dependencies retain their separate licenses.
- Kept the Chinese README as the default and added a complete English README with reciprocal language links.
- Added Simplified Chinese / English interface switching and `?lang=en` deep links, covering menus, settings, export dialogs, validation errors, Worker progress, statuses and accessibility text.
- Language changes preserve the model, layout, undo history and user input. CAD geometry algorithms, millimetre units, file formats and standard fields remain unchanged.
- Added a local SVG GitHub button in the header for opening the source repository.
- The release workflow uses these bilingual notes and publishes Pages, a static-site ZIP and SHA-256 checksums after checks pass.

## Validation / 验证

The release Action runs engine provenance checks, localization and geometry/export tests, a static build and browser conversion/download regressions before publishing. The generated demo is used for public tests; no private CAD model is distributed.

发布前由 Action 执行内核来源检查、多语言及几何/导出测试、静态构建和浏览器转换/下载回归。公开测试使用程序生成的示例，不包含私有 CAD 模型。
